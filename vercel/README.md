# Tanggap Lampung — Vercel Static

Versi ini khusus untuk deployment halaman `index.html` sebagai website static di Vercel.

## Isi
- `index.html` — halaman website
- `vercel.json` — konfigurasi Vercel

## Deploy
1. Upload isi folder ini ke repository GitHub.
2. Di Vercel pilih **Add New → Project**.
3. Import repository tersebut.
4. **Application Preset** seharusnya tidak perlu dipilih sebagai Rust karena tidak ada `Cargo.toml`.
5. Klik **Deploy**.

Jika repository berada di dalam folder, pilih folder yang berisi `index.html` sebagai **Root Directory**.
